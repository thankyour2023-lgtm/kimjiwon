# 산업연관표 분석 웹앱

2023년 산업연관표(연장표, 생산자가격)를 브라우저에서 분석하는 웹앱입니다. 한국은행이 공표한 기본부문(380)·소분류(165)·중분류(83)·대분류(33) 투입산출표를 모두 사용하여, 한 산업을 분류 수준을 바꿔가며 분석합니다. 별도 서버 없이 방문자의 브라우저에서 Pyodide(WebAssembly 기반 Python)로 계산합니다.

사례 산업으로 열연강판(기본부문 2725)을 다룹니다.

## 사용 방법

1. "자료 불러오기" 버튼을 누릅니다. 분류 연결표와 기본부문 표(약 12MB)를 내려받고 계수 검증을 수행합니다. 처음 로딩은 시간이 걸립니다.
2. "분석 대상 산업"에서 산업을 고릅니다(기본부문 380개에서 검색). 고른 산업이 아래 네 분석에 공통으로 쓰입니다.
3. 각 분석의 버튼을 눌러 결과를 봅니다. 소·중·대분류 자료는 처음 필요할 때 자동으로 내려받습니다.

## 분석 기능

원자료 탐색: 한 행을 고르면 각 열과의 값을 표로 봅니다(기본부문).

최종수요 증가 시뮬레이션: 여러 산업의 국내 최종수요 증가액을 넣어 생산·수입·부가가치유발액과 상위 15개 산업, 전체 산업 CSV를 얻습니다(기본부문).

① 수준별 비교: 같은 산업을 4개 분류에서 각각 계산해 생산유발계수(승수)·수입유발계수·부가가치유발계수를 비교합니다. 분류가 거칠수록 그 산업 자체가 아니라 같은 묶음 산업들의 평균 구조가 반영되어 계수가 달라집니다.

② 핵심산업 지도: 가로축 영향력계수(후방연쇄), 세로축 감응도계수(전방연쇄)의 산점도로 산업의 성격을 봅니다. 두 계수의 전산업 평균은 1입니다. 네 분면으로 전·후방 모두 강한 핵심 산업, 최종재형, 소재·중간재형, 독립형을 구분합니다.

③ 수요 원천: 선택 산업의 생산유발액이 소비·투자·수출 중 어디에서 나오는지 구성을 봅니다.

④ 수출의 국내기여: 최종수요가 늘 때 유발된 효과 중 국내 부가가치로 남는 부분과 수입으로 해외에 새는 부분을 나눕니다.

## 계산 방법과 검증

생산유발액은 레온티에프 역행렬(생산유발계수표) L에 최종수요 벡터 f를 곱해 구합니다(x = L·f). 수입유발액과 부가가치유발액은 각각 수입유발계수표·부가가치유발계수표를 사용합니다. 영향력계수는 생산유발계수표의 열합을 전산업 평균으로 나눈 값, 감응도계수는 행합을 전산업 평균으로 나눈 값입니다.

자료를 불러올 때 세 항등식의 잔차를 확인합니다: (I − Ad)·L = I, Am·L = M, v·L = V. 네 분류 모두 최대 절대 잔차가 1e-6 미만이어야 통과합니다(실제 1e-15 수준). 또한 수입유발계수 + 부가가치유발계수 = 1 이 성립합니다. 대분류 영향력·감응도계수는 한국은행 공표값과 소수 넷째 자리까지 일치합니다.

## 단위

거래표와 유발액은 백만원입니다(1,000백만원 = 10억원). 투입계수표·유발계수표는 단위 없는 계수(비율)입니다. 영향력계수·감응도계수는 전산업 평균을 1로 한 상대지수입니다.

|---|---|
| index.html | 화면 구성 |
